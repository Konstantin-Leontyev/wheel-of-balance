# Колесо баланса

Веб-приложение для распределения 168 часов недели по сферам жизни. Сон обязателен и стоит на 12 часах; ниже 4 часов в сутки его опустить нельзя.

## Локально

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

## GitHub Pages

Сайт собирается GitHub Actions при пуше в `main`. В репозитории: **Settings → Pages → Source: GitHub Actions**.
